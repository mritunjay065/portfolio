## 🌟 Key Highlights & Engineering Features

- **Interactive HTML5 3D Canvas Engine**: Real-time connected cyber particle mesh with dual-tone lighting (deep blues & fiery oranges) linked to user scroll progression.
- **Glowing Interactive Cyber Cursor**: Trailing spring-physics aura ring that reacts dynamically over interactive components.
- **Glassmorphism UI Architecture**: Clean frosted glass cards (`backdrop-filter: blur(16px)`), ambient glow orbs, and seamless dark aesthetics (`#121212`).
- **Dynamic Project Filtering & Details Modal**: Category filtering across Healthcare AI, Computer Vision, and NLP / Security with comprehensive architecture walkthroughs.
- **Fully Responsive**: Fluid scaling across mobile, tablet, and ultra-wide displays with an adaptive mobile navigation drawer.

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/mritunjay065/portfolio.git
   cd portfolio
   ```

2. Open `index.html` in your browser or run a simple local server:
   ```bash
   python -m http.server 3000
   ```
   Then open `http://localhost:3000` in your web browser.
